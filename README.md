# TeorVer-DRIP
Репозиторий с материалами курса "Теория вероятностей", который читается в бакалавриате "Дизайн и разработка информационных продуктов" ФКН ВШЭ в 1-2 модуле

## Авторы курса

Лектор: Полякова Ирина

Семинаристы: Умнов Сергей, Денисов Илья

## Содержание

**lectures**: здесь выкладываются актуальные лекционные конспекты (.pdf).

**seminars**: здесь выкладываются актуальные тетради с семинаров (.pdf или .ipynb).


## Ведомость

Актуальная ведомость на 2026/2027 год доступна по ссылке: https://docs.google.com/spreadsheets/d/12xvOW1YY29BvtSu5fX8kNuu1fUQAm7jdaIA55SoYOW8/edit?pli=1&gid=799727793#gid=799727793

На основной вкладке ведомости продублирована формула оценки курса

Во вкладке с группами Вы можете отслеживать свою накопленную оценку

Вкладка "Экзамен" в течение курса будет пополняться вопросами к экзамену (билеты устного экзамена будут сформированы исключительно по вопросам с этой вкладки)
